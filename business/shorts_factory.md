## 서비스
- 웹 우선 (폰 브라우저 대응) · 매우 디지털스러운 비주얼 · 쉽고 직관적인 버튼 · 부가기능 최소
- 흐름: 풀영상 링크 입력(+보조로 파일 업로드) → 저작권 경고 · 동의(권리 있는 영상만 · 불이익 본인 책임 · 업로드 시 출처 표시 안내) → '생성'(크레딧 차감)
  → 받아쓰기 · AI가 재밌는 구간 5개(각 20~50초) 선정 → 쇼츠 5개(상단 헤드메시지 · 자막 · 배경음 · 선택 음성) 자동 제작
  → 간단 편집(자막 · 헤드메시지 수정, 앞뒤 · 중간 자르기, 색 테마, 무료 배경음 몇 곡) → mp4 다운로드
- 영상 길이 제한: 기본 30분 (업그레이드 60분 검토)
- 보완책(사용자 수락): 파일 업로드 보조 경로 · 권리자 신고 창구 · 이용약관 · 출시 전 법률 검토

## 기능 정리 (11/22 논의안)
### 템플릿 5종 (sf_screens/templates5.jpg)
01 심플 화이트 · 02 네온 다크(기본) · 03 이슈 속보형 · 04 블러 배경 몰입형 · 05 아이보리 노트형
- 생성 전 1개 고르면 5개 쇼츠에 모두 적용, 편집기에서 쇼츠별로 바꿀 수 있음
- 공통 규칙: 자막 한 줄 · 크게 · 숫자/핵심어 강조색 · 본영상 크게 · 원본 자막은 덮기

### 배경음 (BGM)
- 1차: 저작권 걱정 없는 무료곡(CC0)을 직접 골라 분위기 6종 × 2곡 = 12곡 내장
  (신남 · 잔잔 · 긴장 · 감동 · 웃김 · 미스터리). 곡마다 유튜브 업로드 테스트로 저작권 경고 없는지 확인
- AI가 쇼츠 내용 보고 분위기 자동 추천, 사용자는 없음/6종/볼륨만 조절
- 말소리 나올 때 배경음 자동으로 줄이기
- 구독형 음원 사이트(Epidemic, Artlist 등)는 남의 서비스에 넣어 재배포하는 게 막혀 있어 제외
- 2차: 곡 수 늘리기(유료 라이선스 또는 AI 작곡 곡)

### 꾸미기 기능 범위
- 1차(넣음): 템플릿 · 헤드 문구 · 자막 수정 · 자동 강조색 · 자막 박스 이동 · 구간 자르기 · 배경음
- 1.5차(간단한 것만): 이모지 자동 1개(켜기/끄기) · 효과음 3종 · 제목/설명/해시태그 자동 작성(복사 버튼)
- 뺌(복잡 · 품질 관리 어려움): 스티커 자유 배치 · 글자 애니메이션 · 화면 전환 효과 · 필터
- AI 내레이션: 2차로 미룸 (원본 목소리와 겹쳐 품질 떨어지기 쉬움)
