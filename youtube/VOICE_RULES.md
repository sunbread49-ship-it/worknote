## 작업 순서 (매 영상)
1. 대본을 쓸 때 아래 '쓰는 법'을 지킨다.
2. `python render.py <ep> --stills` 또는 렌더 시 자동으로 `out/<ep>/음성점검.txt` 생성 → **확인 필요 0곳이 될 때까지 고친다.**
   남은 경고가 의도적이면(예: 문장 사이 자연스러운 쉼) 이유를 적고 넘어간다.
3. 사용자에게는 점검을 통과한 영상만 보낸다.

## 쉼 · 억양 (쓰는 법)
- **짧은 쉼은 ' / ' (0.12초), 긴 쉼은 ' // ' (0.3초)**: 조각마다 따로 녹음해 이어 붙인다. 자막에는 안 보인다. (롱폼 · 쇼츠 공통)
  예) `한 말은 이거였어요. // 한 달에? / 그렇게 많이 줘요?`
- 쉼표(,)는 짧은 쉼(pause short)으로 자동 변환. `[pause]`는 길고 어색해서 쓰지 않는다.
- 첫째 · 둘째 · 셋째는 자동으로 따로 떼어 차분하게 읽는다(`첫째, ` → `첫째 / `).
- **말꼬리 조각으로 끝내지 않는다**: "김장훈 씨처럼요." "900만 원까지요." → 끝 음정이 올라가 웃기게 들림.
  완결된 문장으로: "김장훈 씨도 그렇게 시작했어요." "900만 원까지 돼요." (점검기: 끝 음정 +18% 넘으면 경고. '처럼요'는 +33%였음)
- 질문은 쉼표로 잇지 말고 문장마다 물음표로 끊는다.
- 따옴표 속 대사는 앞에 ' // '로 한 박자 쉬고 시작한다.
- 한 문장이 30음절을 넘으면 쉼표나 ' / '로 호흡을 준다(점검기: 보통보다 25% 빠르면 경고).

## 자동 점검이 보는 것 (tools/voice_check.py)
