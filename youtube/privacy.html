Gaemi Calculator Uploader — Privacy Policy & Terms of Service

This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

1. What this tool is

Gaemi Calculator Uploader is a private command-line tool used only by the owner of the YouTube channel "개미의 계산기" (@개미의계산기). It uploads the owner's own original educational videos (long-form and Shorts) to the owner's own channel and sets titles, descriptions, tags, custom thumbnails, Korean captions and scheduled publish times. It has no other users and is not distributed.

2. Data accessed

  • Through OAuth 2.0, the tool accesses only the channel owner's own YouTube channel, with the scopes youtube.upload and youtube.force-ssl.
  • It reads the channel's basic information (name, subscriber count) to confirm the correct channel before uploading.
  • It does not collect, store, sell or share any data about viewers or any other YouTube users.

3. Storage and security

The OAuth refresh token is stored only as a private environment variable in the owner's private execution environment. No API data is stored beyond a local log of the owner's own uploaded video IDs. No data is shared with third parties.

4. Revoking access and deleting data

  • Access can be revoked at any time at Google security settings (third-party access).
  • When access is revoked, the stored token stops working and is deleted from the environment, and the local upload log is deleted within 7 days.

5. Terms of Service

The tool is provided for the channel owner's internal use only. Use of YouTube features through this tool is subject to the YouTube Terms of Service and the YouTube API Services Developer Policies.
