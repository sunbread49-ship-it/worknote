# 네이버 블로그 글 규칙 (2026-11-28 사용자 · 영상 주제 → 블로그 자동화)

`python3 tools/blog.py episodes/<ep>` → `out/<ep>/blog/`
- 영상 화면을 **자막만 빼고** 캡처(로고 · 챕터 표시는 남김) → 그중 7~10장을 글 흐름에 맞게 골라 끼움
- 글은 Gemini(텍스트 모델)가 대본 · 숫자 주석 · 장면 목록을 보고 **블로그 말투로 새로** 씀 (대본 복붙 X)
- 결과: `post.html`(미리보기 · 그대로 복사해 붙여넣기 쉬운 형태) · `post.md` · `naver.txt`(스마트에디터용: [사진 01] 표시) · `images/01.jpg…` · `tags.txt`

## 글 스타일 (프롬프트에 그대로 들어감)
- 말투: 친근한 해요체 · 1인칭("저도", "오늘은 ~ 정리해 볼게요") · 4060 독자가 폰으로 읽기 편하게
- 제목: 검색어를 맨 앞에(예: "엔비디아 주가 · 시스코 닷컴버블") + 궁금증 한 조각 · 35자 안팎
- 도입: 독자 고민에 공감하는 질문 2~3문장 → 오늘 글에서 알게 될 것 (답은 아직 안 줌)
- 본문: 소제목 4~6개 · 문단은 2~3문장 · 사진 하나마다 앞뒤로 설명 · 숫자는 **굵게** · 전문용어는 한 줄 풀이
- 중간중간 `📌 한 줄 정리` 박스 1~2번 · 이모지는 소제목 앞 정도로만 (남발 금지)
- 끝: 결론 3줄 → 영상 링크(있으면) → 댓글 질문 → 면책 문구
- 길이: 2,000~3,000자
- 금지: 특정 종목 매수 · 매도 권유, 수익 보장, 과장된 낚시 문구, 영상 대본 문장 그대로 옮기기, 사실과 다른 숫자 추가(숫자는 대본 · 주석에 있는 것만)
- 출처 줄: 자료 출처 + "달러 기준 · 배당 · 환율 제외" 같은 계산 조건

## 사람이 하는 일 (지금)
- `post.html`을 열어 전체 복사 → 네이버 블로그 스마트에디터에 붙여넣기 (사진이 같이 안 붙으면 `images/` 폴더 사진을 순서대로 올림)
- 자동 발행은 사용자와 논의 후 결정 (네이버는 공식 글쓰기 API가 사실상 막혀 있어 브라우저 자동화 · 예약 발행 등 방법을 골라야 함)
