# 장면 템플릿 가족 (2026-11-22 사용자 규칙)

**규칙: 같은 결의 내용은 템플릿이 가족별로 4~10종. 롱폼 한 편마다 가족별로 4종 이상을 섞어 쓴다 (같은 형식 최대 2번).**
기본 톤은 채널 어두운 배경 + 빨강·초록 포인트. 변주 안에 실제 자료(인물 사진 · 공시 · 기사 · 논문 · 인터뷰 · 뉴스 영상 · 뮤비 등)를 꼭 넣는다.

| 가족 | 템플릿 (type) | 메모 |
|---|---|---|
| 순위 | `leaderboard`(가로 막대 · 얼굴 동그라미) · `facerank`(사진 크기 + 왕관 · 가림 가능) · `podium`(시상대) · `columns`(세로 기둥 + 얼굴) · `lollipop`(선 + 점, 항목 多) · `matrix`(표) · `hbars` | 내레이션은 1위만 크게, 나머지 묶어서 요약 |
| 비교 A vs B | `duel`(카드 2장) · `photovs`(실사진 반반 + = / VS) · `scale`(저울 기울기) · `receipt`(영수증) · `versus` · `twopanel` · `split` | |
| 증거 · 실제 자료 | `doc`(공시 원문 캡처 + 형광펜) · `press`(기사 스크랩) · `chart`/`photoline`(주가) · `punch`(인물 사진 + 한 방) · `portrait`(인물 소개) · `showcase`(사진 · 로고) · `news`(속보 화면) · `xpost`/`reddit`(SNS) · `media` | 언론사 사이트는 환경 허용 목록에 추가해야 실제 캡처 가능 |
| 구조 · 원리 | `chain`(지분 사다리 · 흐름) · `flow` · `hub` · `timeline` · `domino` · `pyramid` · `waterfall` | 글 나열 대신 도형 · 선 |
| 숫자 한 방 | `kpi` · `bignum` · `capsule` · `ticket` · `counter` 계열 | |
| 전환 · 문장 | `kinetic`(영상 배경) · `title` · `card` · `checklist` · `quote` · `outro` | |

## 포인트 장면 (지식채널 · 11/22 사용자)
- `accent_simple`: 아이보리 수첩 위 3색 카드 한 장 · 큰 요소 하나 + 문구 한 줄 (거창한 구성 X). 롱폼 1편에 3~4번, 반전 · 핵심 숫자 순간에만.
- 색 조합 4종 `ACCENT`: neon(형광 연두 · 웜그레이 · 블랙) · dinner(짙은 초록 · 오프화이트 · 핑크) · coffee(웜그레이 · 파랑 · 화이트) · notyet(바닐라 · 파랑 · 주황)
- 주제와 상관없이 포인트용으로 돌려 쓴다. 단 **내용이 특정 색을 말할 때는 그 색과 어긋나는 조합 금지** (예: 9호선 '골드' 이야기에 형광 연두 X).

## 그림 먼저 · 새 도안 계속 시도 (2026-11-26 사용자 확정)
- 말하는 내용은 기본적으로 **그림 · 도형 · 도식**으로 보여 준다. 글자만 있는 장면은 예외(인트로 한 줄 · 결론 한 줄 정도)
- 매 편 **새 도안을 1개 이상** 시도한다(사용자가 말하지 않아도). 좋으면 자주 쓴다
- 이모티콘 크기의 작은 포인트(`pins`: ring · arrow · box · dot)를 말에 맞춰 · 장면당 1~3개 · 남발 금지
- 11/26 새 도안: building(회사 = 층별 건물) · drop(가격표가 바닥을 뚫고 지하실로) · dominoes(원인→결과 도미노) · ladder(가격 자에 다음 정거장 깃발)
- 같은 장면 타입은 한 편에 2번까지 · 연달아 금지 (차트처럼 데이터 장면도 색 · 구간 · 포인트로 변주)
- 11/26 사용자 아이디어: **중간 퀴즈 + 3초 카운트다운** — "3초 드릴게요. 3, 2, 1. 아셨나요? 정답은…" → 썰 → 다음 퀴즈. 주제에 맞을 때만 가끔(한 편 1~3개). 도구: quizcard (choices · answer · countdown_on · reveal_on) — 오른쪽 위 원형 타이머 + 틱 소리

## HyperFrames (2026-11-26 도입 시험) — HTML+GSAP로 장면을 영상으로
- 설치: `youtube/hf` (npm `hyperframes@0.9.98` 고정 · 공식 heygen-com/hyperframes · 텔레메트리 끔). 시험 장면: `hf/quiz/index.html` → `npx hyperframes render -q looks -w 3 -o quiz.mp4`
- 규칙(공식 스킬 요약): 타임라인 1개 `{paused:true}` 를 `window.__timelines["<composition-id>"]`에 등록 · `fromTo`만 · `Math.random`/타이머 금지 · 글꼴은 `@font-face`(assets/fonts)
- 모션 원칙: 도착은 느리게 긴 꼬리(expo.out/power4.out) · 퇴장은 40~50% 짧게(power3.in) · 다음 요소는 앞 요소가 30~50% 진행됐을 때 · 단어 간격 60~120ms, 목록 40~80ms · 제목은 단어별 blur 8px→0 (0.13~0.2초), 착지 후 정지 · 숨쉬기/둥둥 반복 금지 · 전환은 화면 속 물체가 원인이 되게
- 시간은 TTS 박자에서 계산(예: 퀴즈 C0='셋' 시각, RV=정답 줄 시작)
- **사용 규칙 (11/26 사용자: "주식 · 지식 둘 다 핵심 포인트에 적극 활용")**: 편마다 눈에 띄어야 할 장면 2~4개를 `type: hf`로 — 퀴즈(`quiz`) · 핵심 숫자 한 방(`stat`, 주식은 `theme: navy`) · 결론/명대사(`headline`). 나머지는 기존 엔진. 같은 템플릿 2번 이하 규칙은 hf에도 그대로.
- 렌더 비용: 무료(로컬 CLI · Apache 2.0 · API 호출/크레딧 없음 · 텔레메트리 끔). 시간만 듦: 장면 10초당 약 2~3분 → 한 편 3~4장면이면 +10분 정도. 같은 내용은 다시 안 구움(해시).
- (11/27 사용자) **같은 장면 틀은 한 편에 1번만**(퀴즈만 예외) · **상상실험 = 어두운 톤 통일, 생활원리(생활상식) = 밝은 톤** · 말만 하는 장면 금지 → 그 말을 '움직이는 도식'으로(위도 고리 · 계기판 · 관성 · 해일 단면 · 공전 · 볼록 지구 · 체중계 · 하루 시계: engine/hfscene2.py)
