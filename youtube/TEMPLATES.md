# 장면 템플릿 가족 (2026-11-22 사용자 규칙)

**규칙: 같은 결의 내용은 템플릿이 가족별로 4~10종. 롱폼 한 편마다 가족별로 4종 이상을 섞어 쓴다 (같은 형식 최대 2번).**
기본 톤은 채널 어두운 배경 + 빨강·초록 포인트. 변주 안에 실제 자료(인물 사진 · 공시 · 기사 · 논문 · 인터뷰 · 뉴스 영상 · 뮤비 등)를 꼭 넣는다.

| 가족 | 템플릿 (type) | 메모 |
|---|---|---|
| 순위 | `leaderboard`(가로 막대 · 얼굴 동그라미) · `facerank`(사진 크기 + 왕관 · 가림 가능) · `podium`(시상대) · `columns`(세로 기둥 + 얼굴) · `lollipop`(선 + 점, 항목 多) · `matrix`(표) · `hbars` | 내레이션은 1위만 크게, 나머지 묶어서 요약 |
| 비교 A vs B | `duel`(카드 2장) · `photovs`(실사진 반반 + = / VS) · `scale`(저울 기울기) · `receipt`(영수증) · `versus` · `twopanel` · `split` | |
| 증거 · 실제 자료 | `doc`(공시 원문 캡처 + 형광펜) · `press`(기사 스크랩) · `chart`/`photoline`(주가) · `punch`(인물 사진 + 한 방) · `portrait`(인물 소개) · `showcase`(사진 · 로고) · `news`(속보 화면) · `xpost`/`reddit`(SNS) · `media` | 언론사 사이트는 환경 허용 목록에 추가해야 실제 캡처 가능 |
| 구조 · 원리 | `chain`(지분 사다리 · 흐름) · `flow` · `hub` · `timeline` · `domino` · `pyramid` · `waterfall` | 글 나열 대신 도형 · 선 |
| 숫자 한 방 | `kpi` · `bignum` · `capsule` · `ticket` · `counter` 계열 | |
| 전환 · 문장 | `kinetic`(영상 배경) · `title` · `card` · `checklist` · `quote` · `outro` | |
