# 스킬 상자 — 주식 악어새 · 터지는 영상 4요소

기준 문서: 「터지는 영상 4요소 — AI용 적용 가이드」(사용자 제공, 2026-11-08). 진행 규칙: 바로 고치지 않기 · 질문은 하나씩 · "지금 → 바꿀 것 → 이유" 먼저.
세부 제작 규칙은 SCRIPT_STYLE.md, 주제 보관함은 KEEP.md, 도식 아이디어는 DIAGRAM_IDEAS.md.

## 한 장 요약 (스킬)

```
목표  내 돈이 불안한 개미에게, 과거 데이터로 "그래서 어떻게 보면 되는지"를 주는 8분 30초~10분 영상
감정  불안 · 공포로 들어와서(반전에 반전) → 조건부 희망 · 답으로 나가게. 겁만 주고 끝내지 말 것
      (대사 · 화면에 '절망' '희망' 단어는 쓰지 않는다)
기준  숫자는 실제 데이터로 재계산한 것만 · 첫 5초에 가장 아픈 숫자 · 어려운 말은 비유와 도식으로
순서  트렌드 발굴 → 구성안 → 썸네일 문구 후보(사용자 픽) → 대본 · 화면 → 목소리 → 검수 → 썸네일 · 제목 → 쇼츠
// 나머지는 알아서. 애매하면 시안 여러 개.
```

## 4요소 결정 메모 (지금까지 정한 것)

| 요소 | 상태 | 정한 것 | 남은 질문 |
|---|---|---|---|
| ① 감정 | ○ 결정 | 콜드오픈 → 불안 셋 → 반전 → 조건부 희망 셋. 반전은 2번 이상(EP013: -12% → 39만 원 → "고점 와도 -63%" → "AI가 배터리를 산다"). 썸네일 · 제목은 비아냥 · 회의 · 놀람 등 감정 톤 문구 후보 중 사용자가 픽 | — |
| ② 알고리즘 | △ 진행 중 | 같은 시청자 연작으로 잇기(EP012 반도체 급락 → EP013 2차전지 레버리지). 쇼츠 첫 문장은 처음 보는 사람도 맥락을 알게 | 쇼츠 → 롱폼 · 구독으로 넘어오는 연결 고리(고정 댓글 · 설명란 · 쇼츠 끝 문구) — **아직 미결정** |
| ③ 소재 · 타이밍 | △ 진행 중 | 구글 트렌드 한국 급상승(RSS)으로 후보 발굴 시작 · 킵 상자 운영 · 시의성 주제는 당일~이틀 안 제작 | 네이버 데이터랩 키 등록(사용자 할 일) · "작은 채널 10배 신호" 확인을 주제 선정에 넣을지 · 12개월 흐름(반짝 vs 큰 흐름) 확인 |
| ④ 퀄리티 | △ 진행 중 | 목소리 15번(Umbriel) 1.15배 원음(두 채널 통일) · 문답은 화보형(로댕 누끼 + 도식) · 원리 도식 · 일상 비유 · 인용은 문장 카드 + 자유 이용 사진 · 썸네일 큰 글씨 | 롱폼 이탈 지점 점검(TQQQ 평균 26%) · SCRIPT_STYLE.md를 "목표 · 기준 · 순서"로 짧게 정리할지 |
