# 대본 작성 규칙 (AI 음성 기준, 피드백으로 계속 갱신)

## 채널 코너 (주 2편)
- **A. 주식 궁금증, 숫자로 풀기** — 화제가 된 종목·ETF, 늘 궁금하던 질문을 실제 데이터로 백테스트하고 인사이트를 얻는다.
  레딧·유튜브의 성공담/실패담은 출발점이 아니라 "이런 얘기 들어보셨죠?" 수준의 **대중 여론**으로만 가볍게 언급.
- **B. 매매법 해부** — 대가 또는 온라인에서 핫한 매매법을 규칙으로 옮겨 백테스트하고 뜯어본다.

## 말투
- 구어체: "자,", "근데요", "솔직히요", "아 진짜", "~거든요/~예요/~죠"
- 짧은 문장과 긴 문장을 섞는다. 반전·숫자 공개 직전에는 쉼표로 한 박자.
- 특정 종목 매수·매도 권유 금지. "~해야 한다" 대신 "데이터로는 ~였다".

## AI 음성이 어색해지는 것 (실제 피드백)
| 하지 말 것 | 이유 / 대신 |
|---|---|
| 문장 안 따옴표 `'2년 만에 30배'는요` | 따옴표 앞뒤로 쉬어서 "는 … 요"처럼 끊김 → 따옴표 없이 쓰기 (음성에서는 자동 제거됨) |
| `1억 8천`, `1,000만` 을 숫자 그대로 | "1 억 8 천"처럼 끊어 읽음 → 음성에서는 자동으로 "일억팔천", "천만"으로 바꿔 읽게 처리됨 |
| `302배` 같은 큰 배수 강조 | "삼백, 이 배"처럼 끊어 짚어 주기 (발음 사전 `SAY`에 등록) |
| 쉼표를 안 쓰고 길게 이어 쓰기 | 이 목소리는 쉼표에서 안 쉬던 문제 → 쉼표마다 짧은 쉼 자동 삽입. 쉬고 싶은 곳엔 쉼표 |
| 영어 약어 그대로 | TQQQ→티큐큐큐, SQQQ→에스큐큐큐, SOXL→속슬 등 발음 사전에 추가 |

| 횟수 `19번 중 17번` | 음성에서 자동으로 고유어로: 열아홉 번, 열일곱 번, 스무 번째, 첫 번째 |
| 연도·기간 `1990년엔`, `76년이지만` | 숫자와 조사를 끊어 읽음 → 자동으로 "천구백구십년엔", "칠십육년이지만" |
| 쉼표 숫자 `7,568포인트` | "칠 오백육십팔"로 끊어 읽음 → 자동으로 "칠천오백육십팔포인트" |
| `76년 치`, `다음 해`, `전 해` | 띄어서 끊김 → 자동으로 붙여 읽기(년치, 다음해, 전해) |
| `1등` | 자동으로 "일뜽" |

새로 발견한 어색한 발음은 `engine/tts.py` 의 `SAY` 사전이나 에피소드 `tts.say` 에 추가한다.

## 마무리 (모든 영상 공통, channel.yaml)
1. 댓글 유도: 궁금한 주제·종목·매매법을 남겨 주시면 다음 영상에서 데이터로 파헤친다
2. 고정 멘트: "구독과 좋아요는, 영상 분석과 제작에 큰 힘이 됩니다."
3. 시그니처: "오늘도 감 말고, 숫자로 투자하세요."

## 채널 정보
- 채널명: 개미의 계산기 · 핸들: **@개미의계산기** (channel.yaml `handle`)
- 설명란·쇼츠 설명의 채널 언급은 이 핸들을 쓴다

## 썸네일 (tools/thumbs.py, 에피소드 yaml `thumbs:`)
템플릿 7종(모두 채널 고유 디자인): calc(계산기 LCD) · receipt(백테스트 영수증) · clipping(가상 신문 스크랩+도장)
· diagonal(대각선 분할) · question(진짜일까?) · big_number(큰 숫자) · vs_numbers(숫자 대비)
- 다른 채널 썸네일의 구도·배색·소품 배치는 따라 하지 않는다. 레퍼런스에서는 '문구 공식'만 참고.
- 문구 공식: "~해라!", "~였다는데 진짜일까?", "~ 다 알려준다", "~ 따라만 해라", "~ 미쳤다…!"
  → 매수 권유로 읽히지 않게 따옴표·물음표로 '남들이 하는 말' 형태로.
- 같은 템플릿을 연속 두 편에 쓰지 않기.
