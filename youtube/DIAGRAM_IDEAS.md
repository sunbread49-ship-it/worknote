# 도식 아이디어 노트 (사용자 제공 참고 이미지 8장에서 뽑은 '구조'만)

원본 이미지는 언론 · 출판사 저작물이라 저장 · 재사용하지 않는다. 그림체 · 배치를 그대로 따라 하지 않고,
아래의 '설명 구조'만 우리 팔레트(남색 · 금색 · 민트 · 빨강)와 우리 장면 타입(flow 등)으로 새로 그린다.

| # | 참고 구조 | 핵심 장치 | 우리 채널에서 쓸 곳 (예) |
|---|---|---|---|
| 1 | 단계 파이프라인 (데이터 → 처리 → 결과, 아래에 '오류가 전파됨' 점선 줄) | 위는 정상 흐름, 아래는 문제가 따라 번지는 흐름 | 레버리지 손실 누적, 금리 → 대출 → 소비 전파 |
| 2 | 원인 → 연결망 → 표적 (작은 원들의 네트워크 속 표적 하나) | 수많은 연결 중 '어디를 건드리는가' | 공급망(누가 누구에게 납품), 한 회사 실적이 업종에 번지는 경로 |
| 3 | 세로 단계 띠(모델 구성 → 추정 → 시뮬레이션 → 예측) + 옆에 미니 그래프 | 왼쪽 세로 단계 라벨, 오른쪽 단계별 그림 | 백테스트 방법 설명(규칙 → 데이터 → 시뮬 → 결과) |
| 4 | 번호 매긴 인과 과정 ①→②→③→④ (풍경 단면 위 화살표) | 한 장면 안에 번호 순서로 원인 → 결과 | 금리 인상이 집값까지 가는 길, 환율이 수출주에 닿는 길 |
| 5 | 에너지 피라미드 (단계마다 줄어드는 양 + 새어 나가는 열) | 층마다 숫자, 옆으로 빠져나가는 손실 화살표 | 수수료 · 세금 · 레버리지 비용이 수익에서 새는 구조 |
| 6 | 부품 해부도 (본체 그림 + 번호 핀 + 아래 범례) | 물건 하나를 뜯어 부품별 이름 | 배터리 셀 → 모듈 → 팩 → ESS, 반도체 칩 구조 |
| 7 | 시간 순서 궤적 (발사 → 분리 → 임무 → 귀환, 곡선 경로 위 번호) | 곡선 화살표를 따라 단계 진행 | 버블의 일생(기대 → 과열 → 붕괴 → 회복), 메모리 사이클 |
| 8 | 순환 자금 구조 (회사 박스들 사이 금액 붙은 화살표, 색으로 종류 구분) | 화살표 색 = 돈의 종류(투자 / 구매 약정), 금액 라벨 | AI 순환 금융(엔비디아 ↔ 오픈AI ↔ 오라클 ↔ 코어위브), 지주사 구조 |

## 만들 때 원칙
- 한 화면 한 메시지. 노드는 많아도 5~6개, 강조는 1곳.
- 화살표에 '무엇이 흐르는지'를 꼭 적는다(돈 · 전기 · 주문 · 정보).
- 숫자가 있으면 화살표 위에 금액/비율 라벨.
- 등장 순서(on)로 설명 순서를 따라가게 — 한꺼번에 다 보여주지 않는다.
- 원리 설명용이면 '설명용 그림 · 실제 비율 아님' 표기.
- 다음에 만들 장면 타입 후보: cycle(순환 자금 · 원형 배치), steps(번호 인과 ①~④), pyramid(층별 손실), anatomy(해부도 핀).
